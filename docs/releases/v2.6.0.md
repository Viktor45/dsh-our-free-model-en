# Our Free Model 2.6.0

## Fork 发布通道

本版本是本 Fork（`Viktor45/dsh-our-free-model-en`）的首个自有发布版本：

- 应用内升级的默认清单源改为本 Fork 仓库（raw.githubusercontent.com 优先，jsDelivr 兜底），
  公告 feed 同样改指本 Fork；`feedUrl` 仍然只覆写公告源，不改变升级源。
- 清单签名改用本 Fork 自己的 Ed25519 私钥，公钥 pin 在 `src/updater.js`。
  **上游与本 Fork 是两个互不接受的信任根**：本 Fork 的客户端只接受本 Fork 签名的清单，
  上游的客户端也只接受上游签名的清单。需要回到上游通道时，请换回上游的插件包。
- 目录记录（`catalog/dsh-plugin.json`、`catalog/provenance.json`）的 id、来源仓库与
  revision 指向本 Fork；许可证与上游版权行原样保留。
- 发布私钥不入仓，存放在仓库外的 0600 文件中；CI 通过
  `RELEASE_MANIFEST_PRIVATE_KEY`（PEM 内容）与 `OFM_RELEASE_PUSH_TOKEN` 两个 secret
  在每次推送 main 后重签清单。

## 界面语言

- 桌面壳（`packages/desktop`）的用户可见文案统一为英文：启动页、错误页、标题栏按钮与
  失败提示、服务启动参数错误。
- 独立服务控制台（`packages/standalone/frontend`）的用户可见文案统一为英文：模型页、
  统计页、渠道页、设置页、可见性页、连接页与登录终端。
- 插件本体（`client.js`）保留中英双语字典，按宿主的 locale 切换，本次不改其文案。
- 注释、文档与 CSS 结构未做翻译性改动；浅色主题下搜索框的图标间距改用 class 选择器，
  不再依赖中文 placeholder。

## 安装

插件包为 `dsh-our-free-model-2.6.0.tgz`。托管安装请更新 profile 中的可信 tarball 路径，
再由宿主重新解析依赖；自行安装可通过插件升级页面更新。

## 验证边界

发布前检查签名清单与安装包字节完整性（LF 归一化）、目录记录与来源仓库一致、发布内容
的 revision 对齐，以及全部离线套件通过。真实上游账号调用与 Windows/macOS 安装器安装
不在本次验收范围内；本版本不承诺解除上游客户端、地区或配额限制。

## 回退

恢复 `2.5.9` 的可信插件 tarball，并按宿主安装流程重新解析。保留用户配置、账号及统计数据。
注意 `2.5.9` 属于上游通道，其清单由上游私钥签名；回退后应用内升级将改回上游的信任根。
