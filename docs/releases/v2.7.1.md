# Our Free Model 2.7.1

## 同步上游 2.7.x

本版本把本 Fork（`Viktor45/dsh-our-free-model-en`）同步到了上游 2.7.x：

- 模型工作台（内嵌 magpie 引擎）、订阅车道（Codex / Claude / Gemini / API 导入与本机发现）、
  三种智能路由策略与嵌套路由组、资源库（MCP 资源与客户端配置方案）、聚合渠道页，
  以及桌面端新增的客户端与订阅、资源库、路由组、聚合渠道四个管理页都已并入。
- 渠道排除策略与使用须知声明与上游一致：本插件不提供 WorkBuddy 国内版
  （workbuddy，亦称 CodeBuddy）、WorkBuddy 国际版（workbuddy-ai）与华为云
  Huawei Cloud MaaS（huaweicloud，含 Token Plan），在插件端与桌面端均无法添加、
  登录或通过插件市场安装。
- 上游的信任根没有被引入：清单仍由本 Fork 自己的 Ed25519 私钥签名，公钥依旧 pin 在
  `src/updater.js`，目录记录的 id、来源仓库与 revision 指向本 Fork。
- 清单的文件数上限随上游从 120 调整为 128，以容纳新增的引擎二进制。

## 界面语言

- 上游新增界面的用户可见文案全部译为英文：模型工作台、订阅与额度、资源库、路由组、
  聚合渠道、渠道浏览、概览与侧栏，以及登录终端输出、独立端各接口的错误提示与免责声明正文。
- 插件本体（`client.js`）保留中英双语字典，按宿主的 locale 切换，本次不改其文案。
- 注释、文档与 CSS 结构未做翻译性改动。独立端页面的 `lang` 与标题同步改为英文。

## 修复：macOS 上的存储检查误判

- 独立端的存储检查此前从文件系统根目录逐级 `lstat`，会撞上 macOS 自带的
  `/var` → `/private/var` 与 `/tmp` → `/private/tmp` 符号链接，从而把临时目录下
  的每一条路径都判为非法——独立端在 macOS 上因此无法启动，使用临时目录的离线套件
  也一并变红。
- 检查改为锚定在被管理目录的根上：根以上的路径归操作系统所有，根以内的任何一级仍必须
  是真实目录，根自身若是把目录指向别处的链接依旧拒绝。符号链接与硬链接的既有防护不变。

## 安装

插件包为 `dsh-our-free-model-2.7.1.tgz`。托管安装请更新 profile 中的可信 tarball 路径，
再由宿主重新解析依赖；自行安装可通过插件升级页面更新。

## 验证边界

发布前检查签名清单与安装包字节完整性（LF 归一化）、目录记录与来源仓库一致、发布内容
的 revision 对齐，以及全部 96 个离线套件通过。真实上游账号调用与 Windows/macOS 安装器
安装不在本次验收范围内；本版本不承诺解除上游客户端、地区或配额限制。

## 回退

恢复 `2.6.0` 的可信插件 tarball，并按宿主安装流程重新解析。保留用户配置、账号及统计数据。
注意 `2.6.0` 同样属于本 Fork 通道，其清单由本 Fork 私钥签名。
